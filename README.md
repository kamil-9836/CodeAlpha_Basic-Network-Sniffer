# Basic Network Sniffer in Python

A simple network packet sniffer built using Python and the Scapy library on Windows 11. This project captures live network traffic, analyzes packet structures, and displays source/destination IPs, protocols, and payload previews.

## Prerequisites
- Python 3.14.5
- Npcap (Installed with WinPcap API-compatible mode)
- Scapy (`pip install scapy`)

## How to Run
1. Open Command Prompt or VS Code as **Administrator**.
2. Run the script:
   ```bash
   python sniffer.py
3. Open a web browser or generate network traffic to see source/destination IPs, protocols, and payloads scroll live in your terminal
